# CINEMAX

مشروع عميل وسائط متعدد المنصات قيد التطوير باستخدام Kotlin Multiplatform وCompose Multiplatform.

## الاتجاه التقني
- واجهة عربية/إنجليزية بتصميم داكن.
- تكامل مع إضافات Stremio عبر HTTP addon protocol.
- طبقة منفصلة لمزودي Nuvio؛ تنفيذ JavaScript يتطلب sandbox آمنًا ولم يُفعّل في هذه النسخة.

## الحالة الحالية
هذه نسخة تأسيسية وليست تطبيقًا مكتملًا. لم يُنفذ بعد تشغيل الشبكة الفعلي، إدارة الإضافات الكاملة، تشغيل الفيديو، الترجمة، المزامنة أو حزم المتاجر.

## المتطلبات
- JDK 17+
- Android Studio وAndroid SDK
- macOS وXcode لبناء iOS وتوقيع IPA

## ملاحظات
يجب اختبار التوافق مع كل إضافة على حدة. لا يستضيف التطبيق أي محتوى، ويجب استخدام المصادر المصرح بها فقط.
